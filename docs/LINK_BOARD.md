## Como obter o link público

### Se for **Trello**

1. Abra o quadro (board).
2. Clique em **"Compartilhar"** (canto superior direito) ou no menu **"..."** → **"Compartilhar, imprimir e exportar"**.
3. Em **"Link do quadro"**, copie o link (ex.: `https://trello.com/b/XXXXX/nome-do-quadro`).
4. Se aparecer **"Visibilidade"**, escolha **"Público"** ou **"Qualquer pessoa com o link"** para o professor conseguir abrir sem login.

### Se for **GitHub Projects**

1. No repositório do projeto, vá na aba **"Projects"**.
2. Abra o projeto/board.
3. O link na barra de endereço já é o link do board (ex.: `https://github.com/usuario/projetofacul/projects/1`).
4. Verifique em **Settings** do repositório se **"Projects"** está visível (repositório público ou permissão para o professor).

### Se for **Notion**

1. Abra a página do board.
2. Clique em **"Compartilhar"** (canto superior direito).
3. Ative **"Compartilhar na web"** e copie o link.
4. Opcional: em **"Convidar"**, adicione o e-mail do professor se preferir acesso por convite.

### Se for **Jira** (Atlassian)

1. Abra o board (Scrum/Kanban).
2. O link da URL é o do board (ex.: `https://sua-empresa.atlassian.net/jira/software/projects/XXX/boards/N`).
3. Em **Configurações do projeto** → **Acesso**, garanta que o professor tenha permissão (convidar ou link compartilhável, conforme o plano da Atlassian).

Você pode colar o link no README (seção "Board do projeto"), no e-mail ou no canal que usa com o professor.

## Sugestões para deixar o board melhor para o professor

- **Títulos claros:** Um nome do board que indique a disciplina/projeto (ex.: "Projeto Facul - CRUD Clientes").
- **Colunas visíveis:** Por exemplo: A fazer | Em andamento | Concluído (ou por sprint, se for o caso).
- **Cartões por entrega:** Um card por funcionalidade ou entrega (ex.: "API REST clientes", "Tela de listagem", "Formulário de cadastro", "Integração MongoDB").
- **Descrição ou README:** Se a ferramenta permitir, um texto curto no board ou no primeiro card explicando o projeto e o que cada coluna significa.
